# 终末地模拟终端

本地静态前端，使用原生 HTML、CSS 和 JavaScript，无运行依赖。

运行 `npm start` 后访问 http://127.0.0.1:5173 。也可以直接打开 `dist/index.html`。

首页包含修复机器人、浮空回收、敬请期待三个模块。“修复机器人”已接入关卡选择和 21 个拼图关卡：枢纽区视频的 12 个修复阶段在前，原有 9 关在后，另外两个入口保留准备中提示。首页搜索框可筛选模块。

## 修复机器人

### 自定义关卡

关卡列表最后的“自定义”入口包含“创建关卡”和“导入关卡”。已保存的自定义关卡位于内置 21 关之后、“自定义”入口之前；卡片提供种子查看和删除，通关后按种子对应的独立 ID 保存最佳时间。重复导入同一种子不会生成副本，也不会重置成绩。

创建时输入名称（固定 Δ- 前缀，含前缀共 3–15 个 Unicode 字符）、选择 3×3 至 15×15 棋盘，以及绿、蓝、黄中的 1–3 种颜色。每种颜色都可用 21 种形状（原有 11 种，加上用户图片中的 10 种），允许反复放置同一形状。选择元件后点击棋盘放置，R 或右键旋转；“阻挡块”可点击添加／取消，“固有块”使用当前选择的颜色，点击空格放置、点击已有固有块改色；它在挑战中锁定且计入对应颜色目标。“移除”删除整块元件、单个阻挡块或固有块。缩小棋盘或禁用已用颜色时，需先移除受影响元件。

作者摆出一份完整有效的解答，系统据此生成各色行列目标；生成与导入均验证棋盘尺寸、名称、颜色、形状、越界、重复格、重叠和参考布局的可解性。支持多种合法答案，不要求玩家复现作者的具体摆法。自定义棋盘按窗口尺寸缩放，元件库可滚动，各颜色计数使用独立位置。三色关卡的图形计数使用小正方形，色组间距随格子大小缩放，保留实心、空心和超出目标的斜纹状态。

原有种子使用冻结的 `EFT1` 协议：标准化名称、棋盘边长、按序排列的阻挡格、按颜色及坐标排序的元件解答布局，通过 UTF-8 JSON → Base64URL 无损编码，并附 CRC32 校验。种子包括完整作者布局，不能用作隐藏答案或防作弊机制；无需服务器、时间戳、随机数或外部关卡库，同一种子在不同设备上生成相同的关卡和元件初始朝向。元件添加顺序及格子数组顺序不影响种子；名称、位置、颜色或棋盘尺寸改变会生成不同种子。新增形状或固有块使用 `EFT2`，附加按位置排序的固有块坐标和颜色；仅包含旧形状且无固有块的关卡仍生成原来的 EFT1 种子。两种格式共用保存列表；版本 1 的形状集合和解码结果保持不变，旧关卡 ID 与最佳成绩不变。

关卡保存在当前浏览器的 `endfield.repair.custom.v1` 中；分享种子用于跨电脑导入，成绩保留在各自浏览器。浏览器清理数据会删除这些本地保存；保存失败时页面仍保留可复制的种子，并提供重试。`dist/custom-core.js` 负责校验、编解码与存储，`dist/custom-ui.js` 和 `dist/custom.css` 提供出题、导入界面。

拾取元件时，抓取点固定为最接近元件中心的实际方块，旋转时保持该方块跟随指针。拖动中也可使用右键旋转。R、Tab、方向键等按物理键位识别，并对中文输入法的 Process 事件和仅收到松键事件的情形提供兼容处理。

旋转动画使用同一个元件图形累积角度，围绕抓取方块中心顺时针转动；快速连续旋转从当前动画角度继续，不重建图形。键盘拾取后的旋转同样保持抓取点的屏幕位置。减少动态效果设置会关闭旋转过渡。

从右侧拖动元件到棋盘，用 R 顺时针旋转；已放置的元件可以再次拖动，拖出棋盘可退回元件库。锁定格和障碍格不能覆盖。旋转只改变朝向，不允许镜像。所有元件放置完成，且每行、每列的各颜色数量均满足目标时自动通关。

空心计数条表示未满足目标，实心条表示已有格数，超过目标的每一格分别新增斜纹条；青绿与琥珀独立计数。Tab 或底部按钮切换图形／数字显示。底部提供重置、旋转和音效开关，Escape 取消当前拖动，再次按下返回关卡选择。

键盘可通过 Shift+Tab 反向遍历控件，元件库聚焦后 Enter／空格选择元件，方向键移动，R 旋转，Enter 放置。触屏支持拖放及屏幕旋转按钮。系统减少动态效果设置会禁用过渡动画。

计时从进入关卡开始，重置后重新计时，通关后停止。完成动画后显示“退出修复”和“修复下一模块”；最后一关的下一模块回到第一关。最佳用时保存在当前浏览器的 localStorage，较慢的成绩不会覆盖更快纪录。存储不可用时显示提示并在当前会话保留成绩。

### 还原范围与验证

按参考画面重建了棋盘尺寸、元件形状、目标数量、障碍格、锁定格、元件库、吸附轮廓、旋转、计数、通关闪框及黄色提示。游戏背景使用本地素材与 CSS 模拟暗色虚化环境，不含视频中原游戏的实时三维场景。字体使用系统字体。

`dist/assets/audio/` 的九个 WAV 音效均来自用户最新提供的 `序列 02_1.mp4`，已替换临时使用的 Kenney 素材。按操作画面和音轨低电平间隔截取拾取、旋转、落格和完成反馈；模块选择、关卡选择、显示模式切换分别复用拖拽开始短声、完成提示尾段和选取短声。无效放置与返回提示复用旋转／落格预览片段，不声称是原游戏中同名操作的独立资源。

保留 48 kHz 立体声、原音高及原时长，仅做 35 Hz 高通、轻度底噪抑制、有上限的增益校准和 3/10 ms 边缘淡入淡出。片段时间码、处理信息及输出文件 SHA-256 均见 `sources.json`；这些用户提供的视频采样不标注为 CC0。`bgm.mp3` 仍为用户提供的全局音乐，独立循环、独立开关，切换关卡不重启。

`dist/audio.js` 统一管理预加载、音量、静音和并发播放。选择提示音不会被页面切换截断，Tab 与显示按钮调用同一种切换声音，未改变模式或按键自动连发时不重复发声。当前环境未进行直接听感验证，不声称与原游戏独立音效完全一致。

右下角可选择用户提供的《洪炉》《春景故人来》《衪的指引》三首 BGM，曲目选择保存在当前浏览器。切换曲目从头循环播放，关闭音乐时换曲不会自动开启。页面加载时预加载并尝试自动播放 BGM；如果浏览器拦截有声自动播放，会在首次点击或按键时重试。音乐开关的关闭状态仍会保留。

安装开发依赖后运行 `npm test`：59 项检查覆盖关卡、计数、碰撞、旋转、中心抓取点、连续旋转固定圆心、21 关模拟拖放通关、旧成绩兼容、输入法兼容事件、成绩、资源、音效来源与文件完整性、切屏播放、Tab／按钮声音、静音行为、BGM 自动播放重试及连续循环。新增检查覆盖固定版本种子往返、新旧种子兼容、固有块计数与锁定、损坏数据拒绝、全部元件形状、15×15 三色关卡可解性、尺寸与计数位置计算、出题／导入／删除及自定义最佳时间保存。Happy DOM 仅用于开发测试，游戏运行仍无第三方依赖。另已通过 JavaScript 语法校验与本地 HTTP 可用性检查；未进行真实中文输入法、浏览器端实际拖放或像素截图比对。

## 视频分析与实现

参考视频长约 13.47 秒，分辨率 2560 × 1440。顶部路径栏约占 8.3% 高度；原始六个等宽入口横排，图标位于画面中央，浅灰大号编号位于图标后侧。此版本缩为三个居中入口。

视觉使用低饱和度灰白背景、细线框、噪点、制图辅助网格、中心倒三角、点状圆环与底部低对比度几何波纹。悬停时显示通高黑色斜纹竖条，隐藏编号和标题，出现物件图、网点光晕、黄色双三角和竖向标记。背景圆环、底部图形和悬停物件有缓慢动画，系统减少动态效果设置会禁用动画。

这是根据视频重建的前端版本，并非原游戏源码或素材的逐像素提取。机器人和回收无人机物件图为专门生成的主题素材；原版字体、着色器、精确三维旋转和粒子轨迹未获取，使用系统中文字体与 CSS 动画近似。

首页原始参考画面与游戏分析帧保留在本地 `reference/`（不随站点提供）。


### 浮空回收 · 33 个关卡

首页第二项进入与修复机器人同风格的关卡选择页，展示缩略棋盘、库存数量、升力目标、完成状态和最佳用时。保留原示例 WL-A0007，另按 [北部禁区视频](https://www.bilibili.com/video/BV1m63K6bE3C/) 的顺序录入 20 处回收点、32 个阶段，共 33 关。`salvage-levels.js` 保存每阶段编号、绑缚位置、库存、视频时间及阶段序号。视频中的四级气球实际升力为 6。

左右、上下分别求和 `气球升力 × (该轴坐标 - 中心坐标)`，两者同时为零，且所有气球合法放置、达到总升力要求，才能点击完成回收。格子明暗按距中心的区域区分 ×0 / ×1 / ×2；平衡计算使用各轴自己的距离。可以拖动气球、将已绑缚气球重新移动或拖回右侧库存、重置，成功后返回终端或重玩。键盘可聚焦气球并按 Enter/空格选取，再聚焦绑缚位置按 Enter/空格放置；Delete/Backspace 收回所选气球，Esc 取消拖动或退出。

`salvage-3d.js` 将每块凹口格板建成具有 10 单位厚度、12 个侧面的三维网格，用透视相机投影到 SVG。上下和左右力矩驱动双轴旋转，弹簧阻尼保留转向时的速度，形成连续回弹；射线与当前棋盘平面求交定位落点。拖拽悬停预览也会驱动倾斜。包含格板构建扫描、投影边缘、区域框、双轴指示、青绿平衡扫描及回收等高线波动。遵循减少动态效果设置，退出销毁动画与计时器。

最佳成绩按关卡 ID 存在 `endfield.salvage.records.v1`，记录点击“完成回收”时的用时，排除结果动画时长；慢速重玩不会覆盖更快成绩。结算支持退出回收、重玩、回收下一模块。保留修复机器人的关卡、自定义、记录和全局 BGM。

偏移箭头旁显示对应力矩的绝对值，方向由箭头表示，平衡时显示 0。将棋盘上的气球拖到已占位置会交换两者；从库存拖入已占位置时，原气球返回库存。预览与最终落点采用同一交换规则。

最后的“自定义”入口支持创建/导入关卡。使用 5×5 棋盘，自定 Δ- 名称、绑缚位置及现有四种气球（升力 1、2、3、6），摆出双轴平衡的答案后保存，库存和总升力自动生成。EFS1 种子采用版本固定的规范 JSON、UTF-8 十六进制和校验值，包含完整答案验证数据；规范排序保证操作顺序不影响种子。导入时重新校验合法性与平衡，拒绝损坏种子；相同种子去重并保留最佳记录。支持种子复制、编辑副本、删除和独立最佳用时，关卡存储键为 `endfield.salvage.custom.v1`。

五个音效直接取自本次视频的选取、落格、平衡达成、启动回收、成功提示时段。`assets/audio/salvage-sources.json` 记录剪辑时间与校验值；高通和温和降噪降低录制底噪，未声称已将混音环境声完全分离。素材未覆盖原有机器人音效。

验证覆盖 33 关的独立有限搜索求解与 UI 通关、透视投影和逆向拾取精度、弹簧回弹收敛、非法落点、库存、重置、动画生命周期、最佳记录更新与重载、下一模块、首页集成和 BGM 连续播放。未进行真实浏览器的逐像素或音画同步人工验收。
